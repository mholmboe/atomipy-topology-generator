# Release Notes: atomipy Topology Generator (`atomipy-topology-generator`) v0.1.0

*Released 2026-06-06 · embeds atomipy 0.96*

First versioned release of the standalone web **Topology Generator**, served at
**`topology.atomipy.io`** (and reachable via `atomipy.io/topology`). It is a
lightweight Flask front-end to the atomipy topology engine.

---

## ✨ Features
* **Upload a structure** (`.gro`, `.pdb`, `.xyz`, and `.cif`/`.mmcif` when GEMMI is available) and generate **MINFF** or **CLAYFF** topologies.
* **Export** GROMACS (`.itp`), CHARMM/NAMD/OpenMM (`.psf`), and LAMMPS (`.data`) topologies, plus processed structures (`.pdb`/`.gro`/`.xyz`).
* **Download all outputs as a ZIP**.
* Embeds **atomipy 0.96**, so every generated file now carries a `Generated by atomipy 0.96 on <date>` provenance header.
* App version is shown in the page footer.

## ⚠️ Data Retention
* The results page and README now warn clearly that **results are download-only**: nothing is stored on the server (no database / persistent storage), results cannot be retrieved later, and no one else can access them. Download and keep your own local copy.

## 📝 Notes
* **Beta**: there is no guarantee the output is correct — verify the generated files before use.
* Hosted on Google Cloud Run (`europe-north1`) with a managed TLS certificate.
